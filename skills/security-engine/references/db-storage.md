# Database, Cache & Object Storage Security

## 1. Query Injection Defense Across Engines
- `[RED]` **SQL Injection (`CWE-89`, `A05:2025`, ASVS V1.2.4):** Bind all data values via prepared/parameterized queries (`?`, `$1`, `:name`, `@param`). Never concatenate or f-string/template-interpolate user input into SQL, HQL/JPQL (`CWE-564`), or `text()`/`createQuery()`. Ban `*Unsafe` ORM APIs (`$queryRawUnsafe`, `$executeRawUnsafe`); use safe builders or tagged templates (`prisma.$queryRaw\`...\``).
- `[RED]` **Dynamic Identifier Injection:** When sorting or targeting dynamic columns/tables, map user input strictly through hardcoded server-side allowlist maps/switches before query assembly.
- `[RED]` **NoSQL / ODM Injection (`CWE-943`):** Validate strict scalar types on inputs (reject objects/arrays where strings or ObjectIds are expected) so attackers cannot inject `$ne`, `$gt`, `$regex`, `$where`, `$function`, or `$accumulator`. Enable Mongoose `sanitizeFilter()`/`strictQuery`, strip `$`-prefixed and dotted keys, and disable MongoDB server-side JavaScript (`security.javascriptEnabled: false` or `--noscripting`).
- `[RED]` **Search DSL & LDAP Injection (`CWE-90`):** Build OpenSearch/Elasticsearch queries strictly via typed SDK builders (never string/JSON concatenation). Escape LDAP DNs (RFC 4514) and search filters (RFC 4515).

## 2. Database Network Isolation, Transport & Ephemeral Auth
- `[RED]` **Public Database Exposure:** Never expose database ports (`5432`, `3306`, `27017`) to `0.0.0.0/0` (`PubliclyAccessible=true`) or public subnets. Restrict security groups strictly to app-tier security groups and bind self-hosted engines to loopback/private interfaces.
- `[RED]` **Unverified or Plaintext DB Transport:** Require server TLS (`ssl = on` + `hostssl` + `scram-sha-256` in PostgreSQL `pg_hba.conf`; `require_secure_transport = ON` in MySQL; `net.tls.mode: requireTLS` in MongoDB). Client connection strings MUST use `sslmode=verify-full` with `sslrootcert` (validates CA chain and hostname). Flag `sslmode=disable|allow|prefer|require` or `rejectUnauthorized: false` as `[RED]`.
- `[YELLOW]` **Static DB Passwords:** Prefer private connectivity (AWS PrivateLink, GCP Cloud SQL Auth Proxy `--auto-iam-authn`) and short-lived IAM database authentication (`rds_iam` 15-min refreshed tokens; GCP `roles/cloudsql.instanceUser`). Never use `trust` or `md5` in `pg_hba.conf`.

## 3. Access Control, Least-Privilege Roles & Multi-Tenancy
- `[RED]` **Superuser App Connections & Bypassed RLS:** Never connect runtime apps as `postgres`/`root`/superuser. Split accounts into `migration_runner` (DDL only), `app_runtime_role` (DML CRUD only, `REVOKE CREATE ON SCHEMA public`, `NOBYPASSRLS`, non-owner of tables), and `analytics_ro` (`SELECT` on replicas/redacted views). On multi-tenant PostgreSQL tables, enable BOTH `ENABLE ROW LEVEL SECURITY` and `FORCE ROW LEVEL SECURITY` (preventing table-owner bypass), failing closed (`NULLIF(current_setting('app.current_tenant', true), '')::uuid`).
- `[RED]` **Pooled Tenant State Bleed (PgBouncer Transaction Mode):** Never set session-level `SET app.current_tenant`. Always bind tenant context inside an explicit transaction using `SET LOCAL` (`set_config('app.current_tenant', $1, true)`).

## 4. In-Memory Caches & Queues (Redis, Valkey, Memcached)
- `[RED]` **Unauthenticated / Exposed Cache or Unsafe Deserialization:** Disable Redis `default` user (`user default off`), bind private/loopback interfaces (`protected-mode yes`), require ACL users with scoped commands (`+@read +@write -@dangerous -@admin -eval -evalsha` when Lua is unused) and key prefixes (`~svc_a:*`), enforce TLS (`port 0`, `tls-port 6379`, `tls-replication yes`, `tls-cluster yes`), and patch Redis against `CVE-2025-49844` ("RediShell" Lua UAF RCE, fixed in Redis 8.2.2). On Memcached, disable UDP (`-U 0` anti-DDoS), enable SASL (`-S`) and TLS (`-Z`), and bind internal IP (`-l`). Never deserialize untrusted cache payloads with `pickle`/unsafe serializers.
- `[YELLOW]` **Cache Key Isolation & TTL Hygiene:** Namespace all keys (`tenant:{id}:resource:{key}`), enforce bounded TTLs on session/auth caches, and avoid storing raw secrets/PII.

## 5. Object Storage Hardening (S3, GCS, R2, Azure Blob)
- `[RED]` **Public Bucket Exposure & Unbounded Presigned URLs:** Enable Account/Org Block Public Access (AWS S3 BPA + `Bucket owner enforced`), GCS Public Access Prevention (`storage.publicAccessPrevention` + UBLA), and Azure `AllowBlobPublicAccess = false`. Issue short-TTL (minutes) presigned POST policies / User Delegation SAS constraining `starts-with` key prefix, `Content-Type`, and `content-length-range`. Reject non-TLS requests (`aws:SecureTransport: false`) and unencrypted uploads.
- `[YELLOW]` **Upload Malware Quarantine & Ransomware Immutability:** Upload untrusted files to an isolated ingress bucket, scan asynchronously (e.g., Amazon GuardDuty Malware Protection for S3 with object tagging), block reads until `NO_THREATS_FOUND`, and promote clean files to a serving bucket. Enforce KMS/CMEK encryption, versioning, and WORM Object Lock (configured at bucket creation) on backups/audit buckets.

## 6. Backups, Safe Migrations & Auditability
- `[YELLOW]` **Unencrypted Backups, Unsafe DDL & Missing Audit Logs:** Encrypt backups in transit and at rest (KMS), keep local dumps `0600`/`0700`, isolate backup buckets with Object Lock + WAL/PITR, and run periodic restore drills. Execute schema migrations using expand-and-contract, `CREATE INDEX CONCURRENTLY`, `NOT VALID` + `VALIDATE CONSTRAINT`, and `SET LOCAL lock_timeout = '2s'` / `statement_timeout = '5min'`. Enable `pgAudit` (`pgaudit.log = 'write, ddl'`), MySQL Enterprise Audit (`audit_log`), or MongoDB `auditLog.filter`, shipping off-host without logging secret/PII bind parameters (`log_min_duration_statement = 0` leakage).

## Verification Checklist
- Audit queries/ORMs for string interpolation, `$queryRawUnsafe`, raw `req.body` passed to MongoDB filters, and `sslmode != verify-full` / `rejectUnauthorized: false`.
- Query `pg_roles` (`rolsuper`, `rolbypassrls`) and `pg_class` (`relrowsecurity`, `relforcerowsecurity`); test concurrent pooled queries across two tenants plus unset tenant context.
- Verify Redis `ACL LIST` (`default off`, `-eval` if unused), S3 BPA / GCS PAP policies, and CI migration rules for `lock_timeout`.
