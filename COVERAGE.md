## Part 2: Classified Semantic Controls Across 8 Domains (`167` Controls)

### 1. Web Applications, Frontend, Browser, CMS & DNS ([`references/web-browser.md`](skills/virgil/references/web-browser.md) — `34` Controls)
- **Architecture & Exception Handling:** OWASP ASVS v5.0 Level 2 baseline selection, fail-closed global exception handling (no stack traces/SQL in HTTP `400`/`500`), and zero `catch`-block authentication/signature bypasses.
- **Public Frontend Secrets, Bundles, Source Maps & CMS Hygiene:** Preventing privileged keys (`SERVICE_ROLE`, `sk_live_`, LLM keys, DB URLs) in `NEXT_PUBLIC_*`/`VITE_*`/`EXPO_PUBLIC_*`/`REACT_APP_*`/`NUXT_PUBLIC_*` or compiled bundles; requiring backend RLS/Security Rules behind intentional public keys (`anon`, Firebase); blocking web-root `.env`, `.git/`, and `.bak`/`.sql`/`.dump` files; disabling production `.js.map`/`.css.map` source maps; disabling directory listings (`autoindex off`), WordPress `xmlrpc.php`, `DISALLOW_FILE_EDIT`/`MODS`, REST user enumeration, and abandoned/pirated ("nulled") plugins.
- **Injection & Client-Side Execution:** Context-aware XSS prevention (`eval`, `dangerouslySetInnerHTML`, `v-html`, `javascript:`/`data:` URLs); rich-HTML **DOMPurify** sanitization against **mXSS** and script gadgets + **Trusted Types** CSP; **Service Worker** registration URL/scope allowlisting, per-account/tenant cache keying, and logout purging across SW/IndexedDB/`BroadcastChannel`/Web Storage; **SSTI** and **Client-Side Template Injection (CSTI)** prevention; and **Prototype Pollution** (`__proto__`/`constructor`/`prototype`) defenses.
- **Browser Boundaries, Headers, Sessions & Cookies:** Exact-match CORS allowlists (banning reflected `Origin`, `Origin: null`, `*` with credentials, and legacy JSONP); nonce/strict-dynamic **CSP**, **HSTS** (`preload`), `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY` + `frame-ancestors`, `Cross-Origin-Resource-Policy`, `Referrer-Policy`, `Permissions-Policy`, and stripping `X-Powered-By`/`Server` headers; optional `COOP`/`COEP` cross-origin isolation against XS-Leaks; >=128-bit CSPRNG session ID rotation on login/MFA/elevation; Synchronizer **CSRF** tokens + `Sec-Fetch-Site` Fetch Metadata checks; `__Host-` cookie prefixes, banning parent-domain `Domain=.` cookies, and hashed rotating remember-me tokens with step-up re-auth.
- **SSRF, Redirects, Files, Archives, XML, Electron & SSR/Next.js:** Connect-time IP pinning against **DNS rebinding**, redirect hops, metadata (`169.254.169.254`), RFC 1918/CGNAT/IPv6-mapped/octal-hex IPs, and **HTML-to-PDF renderer SSRF**; Open Redirect allowlisting; canonical **Path Traversal** and **Zip Slip** (`extractall`) prefix checks; **XXE** (`defusedxml`) and magic-byte/CDR isolated file uploads; **CSV formula injection** escaping; `NFKC` Unicode normalization and **Trojan Source** bidi blocking; server-side pricing/entitlement validation and banning client-shipped decryption keys; exact `window.postMessage` `event.origin` verification; **Electron** `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`, `webSecurity: true`, and validated `contextBridge` IPC; TLS 1.3 / AEAD TLS 1.2 termination; Next.js **RSC / `__NEXT_DATA__`** DTO shaping (no raw DB models or preloaded paywall content), authenticated `'use server'` **Server Actions**, and `'server-only'` DAL guards.
- **DNS, Domain, Email, WebRTC & Edge Protection:** Cloudflare **`Full (Strict)`** TLS + **Authenticated Origin Pulls (mTLS)** + CDN CIDR origin firewalling; **dangling DNS** (`A`/`CNAME`/`NS`/`MX`) and delegated-subtree takeover prevention; TSIG-authenticated **zone transfers (`allow-transfer`)**, closed **recursive resolvers (`allow-recursion`)**, and TSIG/GSS-TSIG dynamic DNS updates; **WebRTC TURN** relay ephemeral HMAC auth + RFC 1918/loopback blocking; **SRI (`integrity=`)** and isolating third-party tag managers/widgets off auth/checkout pages; **SPF**, **DKIM**, and root + subdomain **DMARC (`p=reject`)** + null MX; registrar FIDO2 MFA + transfer locks, single-zone DNS API tokens, and blocking unauthorized port-53/DoH/DoT DNS exfiltration tunnels; optional **DNSSEC**, **CAA**, Bot Management, and **HTTP Request Smuggling / Web Cache Poisoning / Cache Deception** audits.

### 2. API Security, Reverse Proxies/Gateways, Authentication (OAuth 2.1, OIDC, SAML, WebAuthn) & IAM ([`references/api-auth.md`](skills/virgil/references/api-auth.md) — `33` Controls)
